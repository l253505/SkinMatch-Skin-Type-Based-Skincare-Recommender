GLOWGUIDE — BABY-PINK STREAMLIT WEBSITE

1. Extract the ZIP file.
2. Back up your existing app.py before replacing it.
3. Copy app.py, the .streamlit folder, and requirements.txt into your
   existing GitHub project folder (SkinMatch-Skin-Type-Based-Skincare-Recommender).
4. Keep the existing notebooks, CSV files, and model files unchanged.
5. Confirm that skinmatch_recommendations.csv and tfidf_vectorizer.pkl
   are in the same directory as app.py. These filenames intentionally
   remain unchanged because the app uses your existing project assets.
6. Open Anaconda Prompt and activate your existing skinmatch environment.
7. Navigate to your existing repository folder, for example:
   cd /d "C:\Users\hp\Downloads\SkinMatch-Skin-Type-Based-Skincare-Recommender"
8. Run: python -m streamlit run app.py
9. Visit http://localhost:8501

The website now displays GlowGuide branding. Your underlying data/model
filenames remain unchanged to preserve compatibility.

Note: Results are educational only; skincare suitability cannot be guaranteed.
